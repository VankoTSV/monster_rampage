# Отваряне на играта в Chrome

1. Стартирайте `run_in_chrome.ps1` от тази папка (десен бутон → Run with PowerShell).
2. Отворете [http://localhost:8000](http://localhost:8000) в Chrome.
3. Оставете PowerShell прозореца отворен, докато играете. За спиране натиснете Ctrl+C.

Браузърните файлове са в `.web-site`; резултатите се пазят локално в браузъра. WASD или стрелки за движение, мишка за посока, ляв бутон или Space за стрелба, Escape за пауза.

Сървърът слуша само на този компютър (`127.0.0.1`), така че страницата не е публична в интернет.
